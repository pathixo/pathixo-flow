# Plan 08-01: Marketing Route Group Layout, Sticky Navigation & Multi-Column Footer

## Goal
Establish the `(marketing)` route group layout shell enforcing the dark visual theme (`#08090A`), implement the sticky navigation header with desktop links, action CTAs, and accessible Radix mobile drawer, and build the 4-column footer with copyright and operational status pill.

## Requirements
- `LANDING-01`: Minimalist dark-themed sticky navigation bar with Pathixo Flow brand mark, desktop links, CTA button, and accessible mobile drawer.
- `LANDING-08`: Multi-column footer with navigation links, copyright (Pathixo Pvt. Ltd.), legal links, and operational status pill.

## Context & Constraints
- Must be scoped with `data-theme="dark"` / `className="dark bg-canvas text-text-primary"`.
- Navigation links must lead to valid on-page section anchors (`#capabilities`, `#channels`, `#workflows`, `#reliability`) or working placeholder routes (`/login`).
- Mobile navigation must use `@radix-ui/react-dialog` for accessible focus trapping, keyboard Escape dismiss, and body scroll lock.
