# Plan 08-02: Editorial Hero Section, Infrastructure Trust Bar & Core Capabilities Grid

## Goal
Implement the high-impact editorial hero section with display typography and peek integration of `ProductPreviewSimulator`, create the monochromatic infrastructure standards trust bar, and build the 6 core capability bento grid.

## Requirements
- `LANDING-02`: High-impact editorial hero section with headline ("Automate the work. Stay in control."), supporting description, and dual CTAs with preview peek.
- `LANDING-03`: Core capabilities section highlighting the 6 pillars (Communication, Workflow, Integration, Monitoring, Client Isolation, Financial Ledger).

## Context & Constraints
- Display typography must match the Linear reference: large, confident, restrained, with high contrast between primary text (`#F5F5F5`) and secondary copy (`#A0A2A8`).
- Product preview must be framed with controlled negative space beneath the hero copy.
- The capability grid must avoid "card soup" — using deliberate visual variety, structured data chips, and distinct icon anchors.
