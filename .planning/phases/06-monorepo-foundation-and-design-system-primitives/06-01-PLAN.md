# Plan 06-01: Monorepo Workspace Foundation & TypeScript Configuration

## Goal
Establish the root pnpm workspace manifest, workspace membership rules, strict dependency hoisting, git exclusions for Next.js build cache, and root TypeScript strict configuration.

## Requirements
- `ARCH-01`: Root pnpm monorepo workspace configuration (`pnpm-workspace.yaml`, root `package.json` with recursive `dev`, `build`, `lint`, `typecheck` scripts).
- `ARCH-05`: Strict TypeScript compiler configuration (`strict: true`, `noUncheckedIndexedAccess: true`).

## Context & Constraints
- The repository previously contained only documentation and CI/CD workflows.
- Existing CI runs `pnpm run lint --if-present` and `pnpm run typecheck --if-present`. Root `package.json` must delegate recursively to workspace packages (`-r`) so CI cannot silently pass empty roots.
- Node.js version is v22 LTS (ADR-001).

<task id="06-01-T2">
<title>Create Root Workspace Configuration Files</title>
<action>
Create:
1. `E:\Flow\pnpm-workspace.yaml`:
   ```yaml
   packages:
     - 'apps/*'
     - 'packages/*'
   ```
2. `E:\Flow\.npmrc`:
   ```ini
   auto-install-peers=true
   node-linker=isolated
   strict-peer-dependencies=false
   shamefully-hoist=false
   ```
3. `E:\Flow\package.json`:
   ```json
   {
     "name": "flow-monorepo",
     "version": "2.0.0",
     "private": true,
     "packageManager": "pnpm@9.15.4",
     "scripts": {
       "dev": "pnpm --filter web dev",
       "build": "pnpm -r run build",
       "lint": "pnpm -r run lint --if-present",
       "typecheck": "pnpm -r run typecheck --if-present",
       "clean": "pnpm -r run clean"
     },
     "devDependencies": {
       "typescript": "^5.7.3",
       "prettier": "^3.5.1"
     }
   }
   ```
</action>
<verification>
Run `pnpm -v` and verify workspace structure recognition.
</verification>
</task>
