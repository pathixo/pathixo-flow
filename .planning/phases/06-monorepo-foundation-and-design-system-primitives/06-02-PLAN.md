# Plan 06-02: Centralized Design Tokens Package (@pathixo/design-tokens)

## Goal
Create `@pathixo/design-tokens` with authoritative dual-theme token definitions (dark marketing canvas `#08090A` and light app canvas `#F7F7F4`), 4px spacing scale, 2px–6px restrained corner radii, CSS variables (`tokens.css`), and a shared Tailwind preset.

## Requirements
- `DESIGN-01`: Dual-theme token definition in `@pathixo/design-tokens`.
- `DESIGN-02`: 4px grid and 2px–6px radii mapped via CSS custom properties and Tailwind preset.
- `DESIGN-04`: Anti-AI-slop rules enforced (no purple/pink gradients, no neon glows, no glassmorphism).

## Context & Constraints
- CSS custom properties must use space-separated RGB values (`247 247 244`) so Tailwind's `<alpha-value>` opacity modifiers (`bg-brand/10`, `border-border/20`) compute accurately without breaking.
- Dark theme tokens are specifically tuned for marketing surfaces to prevent OLED smearing and optical halation (avoiding `#000000`).
