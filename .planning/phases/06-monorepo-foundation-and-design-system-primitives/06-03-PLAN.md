# Plan 06-03: Accessible UI Primitives Component Library (@pathixo/ui)

## Goal
Build `@pathixo/ui`, a headless accessible component library wrapping Radix UI and Lucide icons, styled strictly with Pathixo Flow design tokens (4px grid, 2px–6px radii, anti-AI-slop compliance).

## Requirements
- `DESIGN-03`: Accessible UI primitives (Button, IconButton, Badge, StatusBadge, Dialog, Drawer, Card, Separator, Table).
- `DESIGN-04`: Anti-AI-slop rules enforced (no glowing borders, no purple/pink gradients, no glassmorphism).

## Context & Constraints
- `react` and `react-dom` must be declared as peer dependencies to avoid duplicate React instances in the monorepo.
- `StatusBadge` must mandate both a status dot or Lucide icon and text label; color-only status communication is prohibited by WCAG AA.
- Buttons and cards must enforce 4px radii (`rounded-md` or `rounded-lg`), rejecting ubiquitous `rounded-full` pills.
