# Plan 06-04: Next.js 15 Web Application Scaffold & Monorepo Integration (apps/web)

## Goal
Scaffold `apps/web` with Next.js 15 App Router, React 19, and Tailwind CSS v4. Link `@pathixo/design-tokens` and `@pathixo/ui` via `transpilePackages`, configure the global root layout with Geist fonts, and establish an initial smoke test page validating token rendering and production build pass.

## Requirements
- `ARCH-02`: Next.js 15 App Router initialized in `apps/web` with single global root `layout.tsx`.
- `ARCH-04`: `@pathixo/design-tokens` and `@pathixo/ui` linked via `workspace:*` and transpiled on-the-fly.

## Context & Constraints
- Must maintain a single global root `app/layout.tsx` containing `<html>`, `<body>`, and Geist fonts to prevent full browser reloads when navigating across route groups in subsequent phases.
- `next.config.ts` must declare `transpilePackages: ['@pathixo/ui', '@pathixo/design-tokens']`.
- Production build (`next build`) and typecheck must pass without errors or warnings.
