# Plan 07-02: Interactive Simulator Composite & Responsive Integration

## Goal
Assemble the modular stage inspectors into a single interactive client simulator (`preview-simulator.tsx`), featuring step-by-step pipeline connection rails, simulation action buttons (`Simulate Message`, `Trigger Duplicate Guard`, `Inspect Payload`), responsive mobile scaling, and page mounting.

## Requirements
- `PREVIEW-02`: Interactive 3-stage delivery pipeline simulation (Ingest $\to$ Worker $\to$ Financial Ledger).
- `PREVIEW-04`: Responsive preview scaling and peek fold adaptation across viewports.

## Context & Constraints
- Must be a client component (`'use client'`) since it maintains interactive simulation states.
- Transitions must be snappy ($\le 150\text{ms}$) and CSS-first.
- Responsive layout must adapt cleanly from large desktop ($1440\text{px}$) down to mobile ($375\text{px}$) with zero horizontal scrolling.
