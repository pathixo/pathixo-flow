## Goal
Build the modular subcomponents for the product preview: the obsidian window frame (`window-shell.tsx`) and the 3 stage inspection components (`ingest-stage.tsx`, `worker-stage.tsx`, `ledger-stage.tsx`) using real DOM/SVG primitives, Geist Mono typography, and firewall-safe mock data.

## Requirements
- `PREVIEW-01`: Dashboard snapshot built using real frontend DOM/SVG components (zero raster images).
- `PREVIEW-03`: Firewall-safe mock data (dummy phone ranges `+1-555-0192`, sanitized demo tokens).

## Context & Constraints
- Component styling must strictly use design tokens from `@pathixo/design-tokens` and primitives from `@pathixo/ui`.
- All mock phone numbers must use the reserved `+1-555-0100`..`+1-555-0199` range to prevent triggering `.github/workflows/security-firewall.yml`.
- Corner radii must strictly adhere to 2px–6px.
